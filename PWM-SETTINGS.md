# Профиль швейного привода

В версии 0.3.0 фиксированные уровни заменены настройками `$33`–`$36`. Они задают заполнение аппаратного PWM в процентах, а не напряжение или обороты. Значения сохраняются в EEPROM, отображаются командой `$$` и не требуют пересборки прошивки.

| Настройка | Назначение | Заводское значение |
|---|---|---:|
| `$33` | Обрезка M6/M30, импульс 1000 мс | 20,0% |
| `$34` | Нейтраль: останов, M5, S0, программный сброс, запуск PWM | 50,0% |
| `$35` | Автоматическая скорость при стежке от 8 мм | 74,0% |
| `$36` | Автоматическая скорость при стежке до 2 мм; верхняя граница PWM для M3 | 86,0% |

Ввод: от 0 до 100%, точность хранения 0,1%. Десятичный разделитель — точка. Ввод с большей точностью округляется к ближайшей десятой процента. Все четыре значения должны удовлетворять:

```text
0 <= $33 < $34 < $35 <= $36 <= 100
```

Недопустимая команда возвращает ошибку без изменения профиля или памяти. Проверяется каждое присваивание отдельно: при повышении профиля сначала повышайте `$36`, затем `$35`, затем `$34`; при понижении сначала уменьшайте `$33`, затем `$34`, затем `$35`. Порядок зависит от текущих значений — промежуточный профиль тоже должен оставаться допустимым.

## Настройка через терминал

Остановить программу и привод командой M5, затем проверить текущие значения:

```text
M5
$$
```

Например, возврат к заводскому профилю из уже совместимого диапазона:

```text
$33=20
$34=50
$35=74
$36=86
$$
```

При переходе с другого профиля придерживаться указанного выше порядка согласованных изменений. Менять эти настройки разрешено только при остановленном приводе в Idle или Alarm. Они недоступны во время движения, ожидания стежка, обрезки и обычной паузы оператора. EEPROM не перезаписывается при каждом стежке — только при настройке.

Изменение `$34` сразу устанавливает новую нейтраль, сохраняя выключенным OUT1. Даже если изменить нейтраль без движения, необходимо убедиться, что выбранный уровень соответствует останову именно подключённого привода.

## Скорость

В auto-сборке `d²=dx²+dy²` и:

```text
d² <= 4:   PWM = $36
d² >= 64:  PWM = $35
иначе:    PWM = $36 - ($36 - $35) * (d² - 4) / 60
```

Формула интерполирует по квадрату длины без корня. Аппаратное задание рассчитывается в промилле; промежуточный результат округляется вниз до целого промилле. Если `$35=$36`, автоматическая скорость постоянна. При нейтральной коррекции скорости 100% значения на границах точно соответствуют профилю.

В manual-сборке S по-прежнему задаётся в промилле: `M3 S540` — 54%. Старое жёсткое ограничение снизу 58% удалено, поскольку оно мешало другим приводам. Задание не выше `$34` означает останов; верхняя граница — `$36`. `$35` используется только формулой auto. Коррекция скорости шпинделя применяется до этих ограничений. M5/S0 всегда возвращают `$34`, а не 0%.

Между стежками выбранное задание сохраняется. После M6/M30, сброса и других команд останова используется `$34`; отдельный режим обрезки временно разрешает уровень ниже нейтрали по `$33`.

## Сохранение и запуск

Формат EEPROM обновлён с v13 до v14. При обновлении с 0.1/0.2.0 калибровка осей, направления и координатные записи сохраняются, а новые четыре поля получают прежние значения 20/50/74/86%. Поддержаны и более старые форматы v10–v12.

При запуске BoardTest_PwmInit считывает проверенный профиль из flash до включения таймера и задаёт сохранённую нейтраль уже первым значением PWM. Настройка не заменяется на 50% после программного reset. При отсутствии корректной записи применяется заводской профиль; на первом запуске нового типа привода его следует настроить до включения сервопривода.

`$8=50` сохранён для совместимости старых настроек, но больше не задаёт физическую нейтраль; для неё используется только `$34`. `$RST=$` / сброс настроек восстанавливает заводской профиль, а не профиль конкретного привода. Напряжение до запуска MCU или при отсутствии его питания всё ещё определяется внешней схемой.

## Jack A5E-B и измерение напряжений

В задании приведены напряжения педали Jack A5E-B: обрезка 0,3 В, подъём лапки 1,2 В, нейтраль 1,7 В, зона минимальной скорости 2,1–2,7 В, линейная зона 2,7–4,4 В.

**Только при идеальном выходе 0–5 В** уровни 0,3 / 1,7 / 2,7 / 4,4 В математически соответствовали бы `$33=6`, `$34=34`, `$35=54`, `$36=88`. Это пример пересчёта, а не проверенный профиль подключения Jack: для испытанной платы ранее получено 2,8 В при PWM 50%. Требуемые проценты нужно подобрать по фактическому напряжению выхода и реакции привода.

Уровень подъёма лапки в этой версии отдельно не настраивается: документ запрашивает четыре параметра, команда подъёма лапки пока не реализована. Методика измерений и последующей компенсации напряжения: [PWM-CALIBRATION.md](PWM-CALIBRATION.md).
